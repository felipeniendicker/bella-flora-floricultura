# Bella Flora — Floricultura & Afeto

Projeto acadêmico de floricultura em React + Vite, com páginas de início, catálogo, história, cuidados, contato e detalhes de produtos. Sacola interativa e simulação de compra, sem pagamentos reais.

## Executar

```bash
npm install
npm run dev
npm run build
```

## Publicar

Importe o repositório na Vercel e escolha Vite. As rotas são configuradas em `vercel.json`.
